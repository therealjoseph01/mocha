# Mocha EV — cinematic landing page (React)

One continuous, scroll-driven story: driving → range drops → no charger close enough → 0% → request Mocha → a provider is matched → the provider drives to you → charging → back on the road. From there it switches to the provider's side, zooms out to the continental US network, compares fixed chargers with moving providers, shows PowerBridge Pro, explains the two-sided marketplace, and ends at dawn on the CTAs.

**Scroll = distance.** Scrolling moves the car, then burns the range, then brings the provider closer, then fills the battery, then puts the car back on the road.

## Quick look

Open `preview.html` (it's a single file, so just double-click it).

## Develop / build

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ — code-split, with the story copy pre-rendered into index.html
npm run preview:file   # regenerates preview.html
```

`dist/` is already built and can be deployed as static files.

## How it works

| Piece | File |
|---|---|
| Scene order + scroll lengths | `src/scenes.js` |
| All copy, with where each line came from | `src/content.js` |
| Scroll → frame state (the choreography) | `src/engine/director.js` |
| Canvas 2D renderer: road, lights, vehicles, map, US | `src/engine/renderer.js` |
| Orbit camera: one projection from chase view to national map | `src/engine/camera.js` |
| World: highway, streets, routes, lamps, chargers | `src/engine/world.js` |
| Low-poly, brand-agnostic car and pickup | `src/engine/meshes.js` |
| Runtime: scroll smoothing, HUD, captions, a11y | `src/engine/engine.js` |
| Lower-48 map data (generated by `npm run us-map`) | `src/data/usMap.js` |

There's no Three.js. Road → map is the same camera changing pitch (11° → 90°) and distance (11 m → 2.6 km → 4,000 km), so each transition is spatially continuous rather than a cut.

## Accuracy guardrails

Research notes, with sources, are in `RESEARCH_AND_STORYBOARD.md`.

* Every range, mileage and battery number is labeled **Illustrative scenario**. There are no ETAs, charging speeds, prices, earnings or provider counts.
* The phone UI is labeled **Conceptual interface**, because Mocha's real app (`app.mochaev.com`) is behind a login.
* PowerBridge Pro is credited to RoamEnergy, with a compatibility caveat and a link to the tested vehicle list.
* The map shows the contiguous US only, and its dots are labeled illustrative.
* All CTAs link to the real destinations: `app.mochaev.com`, the RoamEnergy Mocha discount link, the privacy page and support email.

## Performance, SEO and accessibility

* JS is about 76 KB gzip for React plus the page, and the engine is a separate 28 KB gzip chunk loaded after first paint. CSS is 6 KB. No images besides the logo and one PowerBridge photo, which is lazy-loaded.
* DPR is capped (1.5 on phones) and there's a pixel budget. Rendering drops to 30 fps when the scroll is idle and pauses in background tabs.
* Every scene is a real `<section>` with headings and copy, pre-rendered to HTML. The page also has a canonical URL, OG/Twitter tags, JSON-LD (`Organization`, `Service` with areaServed = continental US), and `robots.txt` / `sitemap.xml`.
* A "Stranded now? Get help" link is visible from the first frame, and "Skip the story" is the first tab stop.
* Reduced motion: one still frame per scene, with captions laid out as a normal page. Without JS, or if the engine fails, the page falls back to readable static content.
* Tabbing to a CTA inside the film scrolls the film to that moment.
